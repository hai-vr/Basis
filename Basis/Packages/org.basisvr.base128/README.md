# Base128 — for Basis

binary serializing and deserializing integer types as variable length integers.

This is [Wojmik/Base128](https://github.com/Wojmik/Base128) (Base128), repackaged as a Unity Package Manager package so [Basis](https://github.com/BasisVR/Basis) can consume it as a **git dependency** instead of a vendored local tarball. It ships the prebuilt managed assembly only.

- **Upstream:** https://github.com/Wojmik/Base128
- **Version:** 1.2.2
- **License:** MIT — see [LICENSE](LICENSE)

## Install

Add to your project's `Packages/manifest.json`:

```json
"org.basisvr.base128": "https://github.com/BasisVR/BasisBase128.git"
```
