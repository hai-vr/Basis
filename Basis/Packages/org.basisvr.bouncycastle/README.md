# BouncyCastle.Cryptography — for Basis

The Bouncy Castle Cryptography library.

This is [bcgit/bc-csharp](https://github.com/bcgit/bc-csharp) (BouncyCastle.Cryptography), repackaged as a Unity Package Manager package so [Basis](https://github.com/BasisVR/Basis) can consume it as a **git dependency** instead of a vendored local tarball. It ships the prebuilt managed assembly only.

- **Upstream:** https://github.com/bcgit/bc-csharp
- **Version:** 2.5.0
- **License:** MIT — see [LICENSE](LICENSE)

## Install

Add to your project's `Packages/manifest.json`:

```json
"org.basisvr.bouncycastle": "https://github.com/BasisVR/BasisBouncyCastle.git"
```
