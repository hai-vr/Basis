# Newtonsoft.Json — for Basis

High-performance JSON framework.

This is [JamesNK/Newtonsoft.Json](https://github.com/JamesNK/Newtonsoft.Json) (Newtonsoft.Json), repackaged as a Unity Package Manager package so [Basis](https://github.com/BasisVR/Basis) can consume it as a **git dependency** instead of a vendored local tarball. It ships the prebuilt managed assembly only.

- **Upstream:** https://github.com/JamesNK/Newtonsoft.Json
- **Version:** 13.0.3
- **License:** MIT — see [LICENSE](LICENSE)

## Install

Add to your project's `Packages/manifest.json`:

```json
"org.basisvr.newtonsoft.json": "https://github.com/BasisVR/BasisNewtonsoftJson.git"
```
