# Basis Examples

Example content for the Basis framework — demo scenes, interactable prefabs, a mirror,
seats, pickups, and sample scripts to learn from and build on.

Extracted from the Basis monorepo so it can be versioned and installed on its own.

## Requirements

Requires a Basis project. Depends on:

- `com.basis.common`
- `com.basis.framework`
- `com.basis.sdk`
- `com.basis.server`

## Installation

### Basis Package Manager (recommended)

Search for **Basis Examples** in the
[Basis Package Manager](https://github.com/BasisVR/BasisPackageManager) and install.

### Unity Package Manager (git URL)

In Unity: **Window → Package Manager → + → Add package from git URL…**, then paste:

```
https://github.com/BasisVR/BasisExamples.git
```

### Manual (`Packages/manifest.json`)

```json
"com.basis.examples": "https://github.com/BasisVR/BasisExamples.git"
```

## Contents

Demo scenes (`Scenes/`, `Seats/`), example prefabs (`Prefabs/`), a mirror (`Mirror/`),
interactables (`Interactable/`, `Highlight/`), materials, and sample scripts (`Scripts/`).
