# Generator.Equals — for Basis

A source generator for automatically implementing IEquatable<T> using attributes.

This is [diegofrata/Generator.Equals](https://github.com/diegofrata/Generator.Equals) (Generator.Equals), repackaged as a Unity Package Manager package so [Basis](https://github.com/BasisVR/Basis) can consume it as a **git dependency** instead of a vendored local tarball. It ships the prebuilt managed assembly only.

- **Upstream:** https://github.com/diegofrata/Generator.Equals
- **Version:** 3.2.0
- **License:** MIT — see [LICENSE](LICENSE)

## Install

Add to your project's `Packages/manifest.json`:

```json
"org.basisvr.generator.equals": "https://github.com/BasisVR/BasisGeneratorEquals.git"
```
