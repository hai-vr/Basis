# K4os.Compression.LZ4 — for Basis

Port of the LZ4 compression algorithm for .NET. Used by Basis for server-side avatar bundle compression.

This is [MiloszKrajewski/K4os.Compression.LZ4](https://github.com/MiloszKrajewski/K4os.Compression.LZ4), repackaged as a Unity Package Manager package so [Basis](https://github.com/BasisVR/Basis) can consume it as a **git dependency** instead of a vendored local mount. It ships the prebuilt managed assembly only.

- **Upstream:** https://github.com/MiloszKrajewski/K4os.Compression.LZ4
- **Version:** 1.3.8
- **License:** MIT — see [LICENSE](LICENSE)

## Install

Add to your project's `Packages/manifest.json`:

```json
"org.basisvr.k4os.compression.lz4": "https://github.com/BasisVR/BasisK4osCompressionLZ4.git"
```
