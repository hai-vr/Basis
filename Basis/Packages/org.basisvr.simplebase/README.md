# SimpleBase — for Basis

Base16, Base32, Base58, Base85 encoding/decoding library.

This is [ssg/SimpleBase](https://github.com/ssg/SimpleBase) (SimpleBase), repackaged as a Unity Package Manager package so [Basis](https://github.com/BasisVR/Basis) can consume it as a **git dependency** instead of a vendored local tarball. It ships the prebuilt managed assembly only.

- **Upstream:** https://github.com/ssg/SimpleBase
- **Version:** 4.0.2
- **License:** MIT — see [LICENSE](LICENSE)

## Install

Add to your project's `Packages/manifest.json`:

```json
"org.basisvr.simplebase": "https://github.com/BasisVR/BasisSimpleBase.git"
```
